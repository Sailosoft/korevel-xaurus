# Rebrand Docusaurus starter → Korevel Xaurus (soft-blue animated theme + knowledge-base content)

## Context

Repo `Sailosoft/korevel-xaurus` is a **stock Docusaurus 3.10.2 starter** with a clean tree: title "My Site", tagline "Dinosaurs are cool", green Infima palette, template blog/tutorials, outbound template links. Everything below replaces it.

## Decisions (confirmed with user)

- **Brand**: title `Korevel Xaurus` (space, not hyphen) everywhere user-facing; tagline `A personal knowledge base — guides, docs, and books.` Repo/package/folder slug stays `korevel-xaurus` (technical identifier only, never displayed).
- **No external links anywhere in the site**: no GitHub/outbound items in navbar or footer, no `editUrl` (no "Edit this page" links), no outbound links in homepage, and written markdown content uses internal links only. Plan itself contains no URLs.
- **Subject**: personal tech knowledge base; content = Guides + Docs (reference) + one flagship **"Engineering Handbook"** book, all markdown.
- **Structure**: ONE docs plugin, folders `docs/guides/`, `docs/reference/`, `docs/book/`, three autogenerated sidebars in `sidebars.ts` (independent prev/next per section). Default `routeBasePath: docs` kept → URLs `/docs/guides`, `/docs/reference`, `/docs/book`.
- **Blog**: removed entirely (dir, preset block, navbar/footer links).
- **Theme**: static soft-blue Infima palette (light + dark) + **animated gradient accents** (hero bg, brand title, navbar underline, hover states) with `prefers-reduced-motion` honored. No full-site hue cycling.
- **Deployment**: Vercel (host/domain details out of scope for this plan; `url` keeps the starter's placeholder value until a real domain exists, `baseUrl: '/'`).

## Ordered tasks

### 1. Delete template content
- `blog/` (all), `docs/intro.mdx`, `docs/tutorial-basics/`, `docs/tutorial-extras/`, `src/pages/markdown-page.mdx`
- `static/img/undraw_*.svg`, `static/img/docusaurus.png`, `static/img/docusaurus-social-card.jpg`, `static/img/favicon.ico`

- `title: 'Korevel Xaurus'`, tagline above, favicon `img/favicon.svg`; leave `url` placeholder as-is, `baseUrl: '/'`; `organizationName`/`projectName` stay `Sailosoft`/`korevel-xaurus`.
- Remove entire `blog: {...}` preset block; **remove `editUrl` from the docs preset**; remove `image:` from themeConfig (template jpg deleted; og:image out of scope).
- Navbar: `title: 'Korevel Xaurus'`, `logo: {alt: 'Korevel Xaurus Logo', src: 'img/logo.svg'}`; items: `type: 'docSidebar'` for `guidesSidebar`/`docsSidebar`/`bookSidebar` labeled `Guides`/`Docs`/`Book` (left) — **no GitHub/external item**.
- Footer: one column `Docs` (Guides → `/docs/guides`, Reference → `/docs/reference`, Book → `/docs/book`), `copyright: Copyright © ${year} Korevel Xaurus. Built with Docusaurus.` — drop Stack Overflow/Discord/X and the More/GitHub column.

### 7. Content (create markdown; front matter `title`, `description`, `sidebar_position`; internal links only)

- `docs/book/_category_.json` (label `Engineering Handbook`, generated-index link) + 6 numbered chapters (`01-…mdx`–`06-…mdx`, number prefix drives order): Setting Up Your Environment; Code Quality and Review; Testing Strategies; CI/CD; Writing Documentation; Operating and Improving Systems.

### 8. Housekeeping
- `package.json`: keep `"name": "korevel-xaurus"` (slug, not displayed).
- `README.md`: retitle to `Korevel Xaurus`, keep install/dev/build instructions.

## Risks

- **Dead links**: `onBrokenLinks: 'throw'` fails the build on any surviving `/docs/intro` or `/blog` reference (homepage, footer, navbar) — grep before building.
- **External-link sweep**: template `editUrl`, GitHub navbar/footer, Stack Overflow/Discord/X must all be gone; a stray outbound `href` silently reappears via copied template content if not checked.
- **Autogenerated category index pages** assumed at `/docs/guides` etc.; if a link 404s at build, point cards at the section's first doc instead.
- **Animation perf**: only animate `background-position`/`background-size`, never layout properties; always reduced-motion guarded.
- **`url` placeholder** must remain a syntactically valid absolute URL (Docusaurus config requirement) even though no real domain is decided — leave the starter's existing value.

## Validation

1. `npm run typecheck`
2. `npm run build` (catches broken links + sidebar misconfig)
3. `npm run start`: light/dark check, animated hero/title/navbar, nav labels Guides/Docs/Book, prev/next stays inside each section, card links resolve.
4. Grep for stale brand/links: `My Site`, `Dinosaurs`, `Korevel-Xaurus` (hyphenated in display text), `Tutorial`, plus any outbound `href="http` / `https:` occurrence in `docusaurus.config.ts`, `src/`, and `docs/` (the starter's placeholder `url` value is the only allowed exception).

## Out of scope

- Deployment/domain setup (Vercel), og:image social card, i18n, doc versioning, book content beyond the 6 chapters, and any outbound links (explicitly excluded).
