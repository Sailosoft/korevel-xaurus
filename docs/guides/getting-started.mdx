Korevel Xaurus is a personal knowledge base built with Docusaurus. Everything
here is plain Markdown (or MDX), versioned in a repository, and published as a
static site.

## What lives where

The site has three sections, each with its own sidebar and its own
prev/next reading order:

| Section | What it is | Start at |
| --- | --- | --- |
| **Guides** | Task-oriented how-tos. Each guide gets you from a starting point to a working result. | [Getting Started](/docs/guides/getting-started) |
| **Docs** | Reference material to look things up in a hurry - commands, syntax, configuration. | [Git Workflow Cheat Sheet](/docs/reference/git-workflow-cheatsheet) |
| **Book** | The Engineering Handbook: a linear, chapter-by-chapter read. | [The Handbook](/docs/book) |

## Navigating

- Use the **top navbar** to jump between Guides, Docs, and the Book.
- The **left sidebar** always shows the section you are currently reading.
- **Prev/next buttons** at the bottom of a page stay inside the current
  section, so reading the Book never drops you into a guide mid-way.
- Use the **search icon** in the navbar to search across every section at once.
- The light/dark toggle follows your system preference by default and can be
  switched manually.

:::tip

New to the site? Read the [Engineering Handbook](/docs/book) front to back,
then keep the [Docs](/docs/reference) section bookmarked for look-ups.

:::

## Editing this site

Every page is a file in this repository. The [Writing and Organizing
Notes](/docs/guides/writing-and-organizing-notes) guide covers conventions,
and [Adding a Book Chapter](/docs/guides/adding-a-book-chapter) covers the
book-specific workflow. When you are ready to ship, see
[Deploying to Vercel](/docs/guides/deploying-to-vercel).
